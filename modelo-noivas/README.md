# Maison Amora

Modelo editorial fictício para lojas de noivas, com apresentação de estilos, planejador de atendimento e contato direto com a Aldenn.

## Desenvolvimento

```bash
npm install
npm run dev
```

A versão de produção é gerada em `out/` por `npm run build`.

## Mídia editorial

A abertura usa o poster configurado em `lib/hero-media.ts`. A seção de inspiração usa fotografias editoriais próprias para desktop e celular, sem sequência vinculada à rolagem. A infraestrutura de quadros permanece no projeto para uma futura retomada, mas não integra a página atual.

As imagens, a marca e o endereço deste modelo são ilustrativos. Em uma implantação comercial, devem ser substituídos pelos materiais e dados confirmados da loja.

## Validação

```bash
npm test
npm run lint
npm run build
```
