# FF Moda Festa — demonstração comercial

Versão: 0.2.0 · Data: 19/09/2026 · Estado: publicada.

## Publicação

- Endereço público: `https://www.aldenn.com.br/demonstracao-ffmoda`.
- Projeto independente: `modelo-moda-festa/`.
- Exportação estática configurada para o caminho `/demonstracao-ffmoda`.

## Conteúdo confirmado

- Produtos, preços, endereço, telefone e canais sociais foram consultados no site oficial da FF Moda Festa.
- Fotografias editoriais e vídeo foram fornecidos pelo usuário.
- O formulário prepara uma mensagem com nome e ocasião obrigatórios e data opcional para confirmação pela equipe no WhatsApp; não cria disponibilidade fictícia nem confirma reserva automaticamente.

## Direção e ajustes

- Experiência mobile contínua baseada nas três etapas verticais da referência fornecida.
- Carrossel mostra duas peças completas e parte da terceira no celular.
- A vitrine e o detalhe de cada vestido usam somente os 20 produtos já presentes no projeto.
- O detalhe abre sobre a fotografia da peça e envia ao WhatsApp o nome e o link oficial do vestido.
- O cabeçalho não sobrepõe uma ação de WhatsApp ao rosto da modelo.
- O enquadramento do hero preserva a cabeça da modelo em telas largas.
- A ação flutuante usa o símbolo oficial do WhatsApp e dimensão ampliada para toque.

## Evolução futura

- A integração com banco de dados foi reservada para uma etapa futura caso o site seja comercializado.
