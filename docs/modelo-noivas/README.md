# Maison Amora — modelo para lojas de noivas

Versão: 0.1.0 · Data: 17/09/2026 · Estado: demonstração fictícia.

## Escopo aprovado

- Reaproveitar a experiência, os componentes e as mídias editoriais do projeto Taeko Noivas.
- Criar um projeto independente e remover nomes, contatos, endereços, rotas, metadados e identificadores ligados à Taeko.
- Usar a marca fictícia **Maison Amora**.
- Apresentar um endereço ilustrativo na Liberdade, em São Paulo.
- Direcionar WhatsApp e Instagram para a Aldenn.

## Limites

- A marca Maison Amora, o endereço e o atendimento apresentados são fictícios.
- Fotografias são editoriais e demonstrativas.
- O modelo não representa uma loja real, não informa preços e não recebe pedidos.
- O planejador não armazena dados; apenas prepara uma mensagem para o WhatsApp da Aldenn.
