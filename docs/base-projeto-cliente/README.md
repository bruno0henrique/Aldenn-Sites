# Base de projeto para clientes

Estrutura padrão da Aldenn para iniciar projetos com contexto, segurança e histórico verificável.

**Versão da base:** 0.1.0

## Como usar

1. Copie esta pasta para um novo repositório privado.
2. Substitua todos os campos entre `[colchetes]`.
3. Preserve a resposta original do formulário em `docs/entrada-original.md`.
4. Converta a entrada em `docs/briefing.md` e obtenha aprovação do cliente.
5. Defina o escopo antes da implementação.
6. Trabalhe em entregas pequenas, versionadas e testáveis.

## Fonte de verdade

Ordem de precedência:

1. contrato e obrigações legais;
2. decisões aprovadas em `docs/decisoes.md`;
3. `docs/escopo.md`;
4. `docs/briefing.md`;
5. demais documentos;
6. entrada original do formulário.

Formulários são entradas. Alterações posteriores só passam a valer quando registradas e aprovadas.
