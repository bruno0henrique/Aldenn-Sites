# Formulário de descoberta

Use estas perguntas como base para Forms. Adapte somente o necessário ao tipo de projeto.

## Cliente

1. Nome da empresa e responsável pelo projeto.
2. Qual é o negócio da empresa?
3. Quem utilizará ou será impactado pela solução?

## Problema e objetivo

4. Qual problema precisa ser resolvido?
5. Como esse problema é tratado hoje?
6. Qual resultado indicará que o projeto funcionou?
7. O que é prioridade nesta primeira entrega?

## Solução

8. O que precisa ser criado?
9. Quais funcionalidades são indispensáveis?
10. Quais funcionalidades podem ficar para depois?
11. Existem sistemas ou integrações obrigatórias?

## Conteúdo e marca

12. Já existem logo, identidade, textos e imagens aprovados?
13. Quais referências representam a direção desejada e por quê?
14. Existe algo que não deve ser usado?

## Dados e segurança

15. Quais dados serão coletados ou armazenados?
16. Quem poderá acessar esses dados?
17. Existem obrigações legais, contratuais ou internas específicas?

## Operação

18. Quem aprova decisões e entregas?
19. Qual é o prazo desejado e existe uma data obrigatória?
20. Quais acessos, conteúdos ou decisões o cliente precisa fornecer?

## Confirmação

21. Existe alguma informação importante que não foi perguntada?
22. O responsável confirma que as informações podem ser usadas para elaborar o briefing e o escopo?
