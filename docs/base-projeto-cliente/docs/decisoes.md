# Registro de decisões

Não apagar decisões antigas. Quando uma regra mudar, marcar a anterior como `Substituída` e apontar para a nova decisão.

## Estados

- Proposta
- Aprovada
- Rejeitada
- Substituída

## Modelo

### DEC-001: [Título]

- Data: [AAAA-MM-DD]
- Estado: [estado]
- Decidido por: [nome]
- Contexto: [problema ou necessidade]
- Decisão: [o que foi decidido]
- Motivo: [justificativa]
- Impactos: [consequências]
- Substitui: [decisão ou não se aplica]
